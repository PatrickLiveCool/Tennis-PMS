# 企微实收对照：当前实现与接入边界

此切片供本地 demo 使用合成的可信收款流水验收；没有接通真实企业微信账单同步，也不产生真实付款或退款。

## 正常业务与例外

智能体仍通过已有受权限约束的业务 API 报价、锁场、创建订单/充值支付意图。支付意图保留租户、商户版本、业务来源、应付人民币分、渠道订单号和期限；PMS 保留唯一库存与资金事实。

可信收款源包含明确的支付意图关联时，系统校验同租户、原商户、通道、币种及精确外部金额后自动确认。不依赖员工逐单点击。单凭金额、客户昵称、聊天文字、截图或付款人填写的备注不能证明到账或交易归属。

流水没有明确可信关联时只进入待核对。租户 ADMIN 可在后台选择现有支付意图，填写独立核对依据并确认。2026-09-22 新增工作人员智能体路径：显式授予“收款核对”权限的员工可在对话中指定归属，智能体查询真实流水后关联；同时核验当前会话场馆及订单/充值权限。未授权员工、客户和客户智能体不可认领。详见 [工作人员智能体收款核对](staff-agent-reconciliation.md)。确定可信关联的自动入账路径保持。

收款表唯一键为租户＋企业＋商户＋交易号，另有通道＋商户＋交易号全局约束；不能通过改企业或租户重复导入相同外部交易。资金金额与原始关联字段不可修改。实收关联、支付事实、钱包扣款或充值入账、支付意图完成、审计在同一数据库事务提交。失败全部回滚；重试同一流水和同一关联不重复入账。独立可信流水的导入可先落库，方便失败后恢复对照。

晚到账继续调用原订单资金结算：已失效占位不能恢复，钱包预留释放，外部实收形成异常退款任务。已成功支付后又收到另一笔实收也进入资金异常；不能重复确认订单或重复充值。订单退款金额和理由仍由授权员工决定，收款观察不代表退款授权。

## HTTP API

以下后台接口仍需既有 PMS 员工登录并通过租户 ADMIN 检查；新增短期 Bearer 的工作人员工具见上述独立契约。不存在公开接受 JSON 金额并宣称真实到账的接口。

- `GET /api/tennis/wecom/receipts?state=&q=&cursor=`：全租户流水，`items` 与 `nextCursor`；每页 50，按创建顺序游标分页。q 搜索流水 ID / 交易号。状态 `UNMATCHED`、`REVIEW`、`LINKED`、`EXCEPTION`。
- `GET /api/tennis/wecom/payment-targets?venueId=&operationId=`：当前场馆的订单/充值支付意图，默认未完成，指定 operationId 可找历史意图。候选未占用流水，也不等于已核验归属。
- `POST /api/tennis/wecom/receipts/:id/link`：`{operationId,reason}`，以 receiptId 和 operationId 形成幂等关联，禁止改到另一业务。
- `POST /api/tennis/wecom/demo-receipts`：`{operationId,referenceMode:"EXACT"|"UNMATCHED",commandKey}`。仅服务器显式开启且非 production。金额和商户从原 MOCK 支付意图读取，不收用户自报金额。`commandKey` 重试保持同一合成交易号；合成 paidAt 使用支付意图创建时间，稳定复现而不代表真实到账时间。

## 实现接口与后续真实接入

服务端 `TrustedWecomCollectionSource` 只在 adapter 已认证通道、核验企业/商户与租户授权后产生不可变的 `TrustedWecomCollection`。`ingestWecomCollection` 拒绝普通对象和反序列化的冒牌证据。未来真实 adapter 必须从认证后的企微流水或支付服务商事实恢复字段，并按商户绑定隔离、实现分页/检查点/迟到补查；不能直接把用户 JSON 传给认证方法。

当前 adapter 实现仅 `LocalSyntheticCollectionSource`。真实 source 接口中的 `WECHAT` 代表现有支付事实通道，并不代表本切片已经完成企微官方接口联调。真实收款产品选择与上线绑定仍后置。无明确 PMS 对应关系的官方流水继续待核对，不能凭金额自动成交。

本切片不发起真实收款，不同步真实退款，不包含多人付款份额、跨租户钱包、平台分账或结算。后续退款通道需把“授权的退款业务”与“外部退款成功观察”分别处理，不能由聊天或模型补齐金额。

## 验证契约

自动化覆盖身份品牌与不可变事实、合成禁用条件、准确关联自动成交、混合钱包一次扣款、无关联不自动匹配、订单与充值并发争抢同流水、跨租户与改企业防重、晚到账保留新占位、金额/商户不符待核对、员工权限、同事务回调失败回滚、原事件幂等重放，以及搜索/分页不漏记录。真实服务接入与人工验收须另行标注，不能以合成测试代替。
