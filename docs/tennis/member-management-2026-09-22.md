# 会员管理（2026-09-22）

按用户本次确认，将“会员储值”改为“会员管理”，桌面采用 GreenPMS 的左清单、右详情布局。参考原系统 `apps/web/src/pages/MembersPage.tsx` 的 MemberList 与 `styles.css` 的 member-directory / member-list；只修改网球组件。

## 页面行为

- 左侧常驻会员清单，支持姓名、手机号查询。每批 50 人，向下滚动继续加载，也可点击“加载更多会员”；不再截取前 12 人或只展示前 100 人。
- 右侧展示当前会员姓名、手机号、余额、充值记录及资金明细，保留现有充值办理入口。
- 初次进入默认选第一位可用会员；有最近查看/办理的订单或充值记录时，优先选对应会员，其次恢复上次选择。最近业务上下文只消费一次。目标位于后页时按 ID 读取，并在左侧显示选中项。
- 搜索不包含原选中会员时切到结果中的首位，零结果时清空详情；新增后立即选中新会员并清除搜索。
- 快速搜索/分页的旧响应不得覆盖新查询；切换会员重新挂载钱包及充值办理状态。记忆沿用包含身份、租户、权限上下文版本、场馆的 scope。
- 小屏上下排列，会员清单保留独立滚动区。

## 实现边界

采用保留既有视觉的局部调整：中文系统字体、深绿主色、灰绿背景、白色面板、6px 圆角和细边框；稳定双栏，无新增动效，信息密度沿用原后台。设计取值：布局变化 3、动效 1、信息密度 8、素材依赖 1、既有风格保真 10。

新增只读接口 `GET /customers/directory` 与 `GET /customers/:id`；前者以 nickname / id 游标分页，游标绑定租户和搜索词。两者要求员工拥有当前租户的 manage_members 权限。原客户选择 API、资金规则及交易写接口不变；没有数据库迁移。
