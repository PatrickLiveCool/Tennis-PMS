# 外部智能体的同租户可售场馆查询

依据：`decisions-and-acceptance.md` 的“省体无场推荐另一校区”。同租户查找替代场馆属于已确认 MVP；客户原有球友，一次所需多片必须在同一场馆、同一完整时间段内满足。本能力不新增跨场馆组合订单，也不放宽智能体原会话的写入授权。

## 只读接口

`GET /api/tennis/agent/available-venues`

请求头使用已有短期 `Authorization: Bearer <token>`。三个查询参数均必填：

| 参数 | 含义 |
| --- | --- |
| `startAt` | 完整开始时刻，ISO 8601 且带 UTC offset，例如 `2099-09-18T19:00:00+08:00`；URL 编码由客户端执行 |
| `endAt` | 完整结束时刻，同样带 offset；严格晚于开始，按半开区间 `[startAt,endAt)` 查询 |
| `courtCount` | 同一完整时段需要的球场数量，1–100 整数，沿用组合预订的明细上限 |

起止时刻必须落在 15 分钟边界，开始时刻必须在未来。缺省数量、零片、部分日期、无时区时间和额外的 `tenantId` / `venueId` / 主体参数均不会被解释为授权或自动修正。无效参数拒绝请求，不悄悄改成 1 片或 1 小时。

返回包含：

- `query`：规范化为 UTC 的完整起止时刻与所需片数。
- `checkedAt`：该次查询的服务器参考时间。
- `inventoryHeld:false`、`quoteRequired:true`、`switchVenueRequiresNewConversation:true`：明确这是可售查询，没有锁场或正式报价。
- `venues`：当前可完整满足需求的场馆数组，可以包含当前场馆。每项给出场馆名称、地址、时区、目录版本、是否当前场馆、可售片数、可选球场及每片的完整价格明细。
- `suggestedSelection`：同一场馆内按本次价格从低到高选择所需数量的球场，提供球场 ID、人民币整数分合计。相同价格按球场 ID 固定排序。工作人员或客户仍可以从同场馆其他可选球场中选择；后续必须重新正式报价。

候选场馆按所推荐组合的总价、场馆 ID 排序。没有足够球场的场馆不返回；不能把两个场馆各空一片合并成“有两片”，也不能将某片前半小时和另一片后半小时拼成一片完整可售时段。返回不包含预约人、电话、订单、占用编号、课程名称或维护原因。

## 授权与可售依据

服务入口只接收短期 bearer，不接收由外部传入的租户或客户身份。解析授权后，用原绑定 actor 进入业务事务，再核验原会话场馆权限和 delegation 的状态、代次、到期及人工接管情况。

客户仅查询其本人已绑定租户的启用场馆；工作人员仅查询自己当前具有 `read` 和 `book` 权限及场馆范围的启用场馆，租户管理员沿用既有全租户权限。租户、客户、成员与会话的有效状态均沿用现有认证约束。候选场馆和员工场馆范围在同一事务内检查；未创建无授权的身份副本，也未修改全局 `agent-guard`。

候选球场必须启用、有价格，整段没有有效占用。租场、课程、维护与补款待定改期的临时占用都参与冲突判断；相邻边界可售。已过原锁场截止的初始订单占用、已过补款截止的改期临时占用按现有到期语义排除，但查询本身不执行释放或其他跨场馆写入。补款改期未成功时原预约仍占原场，不能随临时占用一起排除。

最短可售时长、场馆时区、全段营业规则、小时价和分时折扣复用 `priceSelectionInTransaction`；未配置/时长不足/营业不完整的球场不作为候选。已有报价和订单的价格快照不受该只读估价影响。

## 从查询到预订

1. 查询所需完整时间和片数，展示明确场馆及候选价格。
2. 选择另一场馆时，由可信 Gateway 切换/建立该场馆的新会话，并取得新的短期授权。
3. 使用新会话的权限重新查验客户和球场，调用正式报价与确认接口。期间被他人预订时按既有库存冲突处理。

原场馆 token 在查询后仍只能向原场馆写入。查询返回的球场 ID、目录版本和估价都不能替代正式报价、库存重验、客户确认或付款回执。

## 验证范围

新增 `tests/tennis/agent-discovery.integration.test.ts` 覆盖替代场馆的完整多片查询、跨场馆/断续空档否定、原报价规则一致性、预约/课程/维护及相邻边界、资产/营业/最短时长、员工范围和权限撤销、人工接管/授权到期、客户停用、到期占用只读语义、原会话跨场馆写入拒绝，以及 HTTP 参数/身份边界。

真实微信入口、外部 Runtime 与人工业务验收仍需实际接入证据。本地查询及模拟数据验证不表示上述外部条件已经完成。
