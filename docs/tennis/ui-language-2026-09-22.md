# 全站 UI 文案与提示整理（2026-09-22）

## 本轮原则

用户要求“说人话，不要把机器语言铺在面上”。该原则已写入项目 AGENTS.md，后续页面和新增功能继续遵循。

- 常驻显示核心字段、金额、当前状态和下一步；重复或显然的说明删除。
- 有用但不影响当前操作的解释放在相关标题旁的信息图标或展开详情中。信息提示支持悬浮、键盘聚焦和点击。
- 真实错误、结果尚未确认、付款期限、取消与退款后果、模拟状态直接显示，不藏进提示。
- 名称和按钮描述实际操作，避免租户、回执、幂等、Runtime 等内部术语出现在日常操作界面。

## 已整理范围

排场与预订、订单列表与抽屉、改期退款、客户与余额、充值和资金流水、收款及企微核对、球场编辑与定价、预订期限、员工及渠道管理、咨询与协助、AI 助手、平台设置和登录公共状态。

预订人默认只显示“姓名”“手机号”及必填标记，去掉“填写后即可核对”“无需办会员或充值”等平铺解释。手机号仍必填且按 11 位中国大陆号码校验，格式错误提示完整保留。本轮只调整信息层级，不改变预订、库存、计价、资金、权限及外部智能体的业务决定。

长编号保留在提示或展开详情里，常用列表展示简短编号。助手保留原有问答和办理入口；本轮没有改写历史回答，也没有调用真实模型。

共用 InfoHint 将弹出说明放在当前原生 dialog 内，避免被模态顶层遮住。Escape 只收起当前说明；Tab 离开、点击别处或滚动时收起。只查看说明不会让编辑弹窗误判为有未保存修改。必填星号不重复进入控件的可访问名称。
