# 租户智能体接入管理

2026-09-22，用户确认参考 GreenPMS，将工作人员智能体访问 PMS 的接入凭据交由租户管理员在 UI 自助管理。参考 GreenPMS `SettingsPage.tsx`、`TokensPage.tsx` 的接入名称、有效期、一次显示、复制、撤销、更换和结果未知恢复体验；保留网球既有 Gateway Key + 人工核验身份绑定机制。

## 使用与权限

“系统管理 → 智能体接入”创建具名接入，默认有效期 90 天，可选 1–365 天。凭据由 PMS 服务端生成 32 字节随机值，只在创建或更换的成功响应中返回；数据库保存 SHA-256，列表、审计和浏览器持久草稿不保存明文。复制到外部智能体或 Gateway 服务端的 PMS 连接配置，再到“渠道账号绑定”绑定经过核验的外部员工账号和实际 PMS 员工。

接入固定属于当前会话租户，管理请求不能指定其他 tenantId。仅当前有效租户 ADMIN 会话可管理，受 CSRF、工作区版本和租户有效状态校验；Gateway 身份及短期委托即使绑定管理员也不能管理 Key 或身份绑定。业务执行继续实时检查员工权限和场馆范围，客户绑定继续受本人范围约束。后台内置助手的模型配置仍由平台维护，外部 Runtime 的模型 Key 在 Runtime 配置。

## 生命周期与并发

- 暂停保留 Key 和身份绑定；恢复继续使用同一 Key。永久撤销不能恢复；到期接入需更换凭据，不能靠恢复延长。更换保留接入 ID 和绑定、立即废除旧 Key，重设有效期；暂停中的接入更换后仍暂停。
- 每次更新要求列表中的 expectedRevision；并发更换只允许一方成功，过期版本返回 GATEWAY_CONFIGURATION_CHANGED。平台原创建/撤销入口保留，平台撤销也更新 revision 并撤销授权。迁移前凭据的原有期限不变。
- 暂停、恢复、更换、撤销与业务写操作使用同一租户事务锁。更新删除相关短期委托、清除消息缓存凭据、提升会话代次；旧消息不得重新签发或追加成功回复。若原会话有未决请求，则转 HUMAN 并将处理中请求标为 UNCERTAIN，由工作人员核对原业务结果后恢复；已提交的订单、账目、请求和命令记录保留。
- 到期校验同时位于初始身份解析及实际业务事务内。暂停后恢复或更换 Key 不复活旧短授权。
- 结果未知时保留不含密钥的操作说明并阻止重复提交，刷新列表核对编号、revision 和更换时间后再处理。创建已成功但未收到密钥可更换或撤销该接入；更换已成功但未收到新密钥则核对后再更换。不能从列表取回原密钥。

## 验证范围

重点验证租户/员工/客户权限隔离，伪造 tenantId 拒绝，CSRF 与工作区版本，明文仅成功签发一次返回，生命周期与已解析身份/短授权撤权，并发更换、到期检查，旧消息不复活及未决交易保留；前端验证凭据不持久化、切页/切租户清除及未知结果恢复。真实企业微信来源验证、账单同步和外部 Runtime 配置联调另行验收。
