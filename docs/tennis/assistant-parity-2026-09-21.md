## 红土场

新增独立材质字段 `surface`，取值 `CLAY`（红土场）、`UNSPECIFIED`（未标注材质）；室内/室外仍独立设置。迁移 026 保留既有球场为未标注，不推断成硬地或非红土。旧客户端未传材质时保留当前值。

场地与定价页支持创建、编辑和显示红土场；排期支持红土筛选、标签及预订；后台助手查询包含材质。材质不改变营业时间、库存、价格或资金逻辑，球场独立小时价沿用原权限、版本和审计。

本地演示场 `红土演示场（本地合成）` 为室内红土、100 元/小时，方便操作验收。浏览器剧本只建立明确标记的合成客户和订单。

## 本地默认模型

用户指定 `https://qintopia.ccwu.cc/v1`、`deepseek_v4`。本机 `.local-workspace/ai-test-defaults.json` 使用现有 AES-GCM 加密保存密钥，权限 0600；`npm run tennis:api` 自动带入，相同配置不增加版本。单元与数据库测试继续注入合成响应，不自动调用真实供应商。

本机代理 DNS 返回 198.18/19 假 IP 时，本地专用解析器通过固定 Cloudflare HTTPS DNS 查询公开 A 记录，再用原主机名完成 TLS 并固定连接 IP；拒绝内网地址和重定向。系统 DNS 等待最多 5 秒，公网 DNS 最多 8 秒。生产启动不加载此本地适配或测试默认配置。
