# Gateway 接入与身份管理操作

本页描述 PMS 后台的本地可运行管理入口。真实微信渠道的账号配置、外部身份校验来源及 Runtime 由外部接入方提供；建立 PMS 凭据或绑定本身不会发送消息、扣款或自动部署渠道。

## 平台运营：创建与撤销接入

平台运营页的“渠道接入”面板先选择租户，再填写接入名称。创建成功后，只在当次页面内存中显示一次 Gateway 凭据；可复制保存到受控的 Gateway 配置。列表随后仅显示名称、编号、启用/撤销状态和创建时间，不读取原 token，也不将 token 放入 localStorage、sessionStorage 或恢复草稿。

每项接入固定属于一个租户。撤销需填写原因，后端按既有可信身份和权限复核；已有订单及资金数据保留。关闭页面或切换租户后若遗失一次性凭据，应核对原列表并撤销旧接入后重新创建，不通过列表取回密钥。

若创建/撤销遇到结果未知，界面保留该次操作描述，暂停新的管理提交。恢复网络后先刷新原列表核对，再结束本次核对；不会自动创建第二份凭据。恢复记录按平台主体及租户隔离，内容不含 token。

## 租户管理员：人工核验并绑定身份

在“场地与定价 → 渠道身份”中：

1. 选择由平台为本租户创建且仍启用的接入。
2. 填写经过人工核验的渠道身份编号。
3. 按姓名查询并选择已有 PMS 客户或员工身份。仅列出已具备可关联主体的身份；不允许手填 customerId，不以手机号相同自动合并或绑定。
4. 填写人工核验依据，确认该渠道账号确属所选本人后建立绑定。

同一主体同时具有客户和员工身份时，两者明确分开显示，必须选择正确身份类型。Gateway 的后续业务能力仍取决于所选主体的真实权限、场馆范围、客户归属、租户状态及会话授权，不因为存在绑定就获得管理员权限。

已有绑定显示渠道身份、接入、PMS 主体、身份类型和人工核验依据。撤销绑定填写原因；撤销接入后，其下尚未独立撤销的绑定会显示“接入已撤销”，避免误认为可继续使用。

未知提交结果同样先核对列表。身份输入和非敏感恢复说明按当前主体、身份类型、租户和工作区版本隔离；不会把另一个租户的目标当作默认绑定对象。

## 本地检查与外部验收

后台应验证平台角色可创建/撤销接入、普通租户无法进入平台配置、仅租户管理员可管理身份、选择目标来自已有主体列表、凭据只显示一次且不进入浏览器持久存储、刷新失败时保留输入及核对入口。

本地检查只证明管理页面和 PMS 契约。真实渠道身份核验、消息收发和外部 Runtime 联调仍须提供对应接入证据后验收。
