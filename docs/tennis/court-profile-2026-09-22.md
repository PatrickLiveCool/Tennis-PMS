# 球场属性与统一保存（2026-09-22）

## 分类依据

球场不是单一的“类型”：材质、环境、尺寸规格、设施条件是独立维度。例如“室外红土标准全场”“有顶棚橡胶练习场”均可成立，儿童红球场的“红球”也不等于红土。

- [ITF Classified Surfaces](https://www.itftennis.com/en/about-us/tennis-tech/classified-surfaces/)：当前产品筛选包含 Acrylic/Polyurethane、Artificial Clay、Artificial Grass、Carpet、Clay、Hybrid Clay、Other。该页面的速度分类为 Slow、Medium-slow、Medium、Medium-fast、Fast；分类不等于 ITF 对产品的认可或背书。此处产品筛选不作为完整材料字典直接照搬。
- [USTA：Find the right tennis level for you](https://www.usta.com/en/home/improve/gear-up/national/find-the-right-tennis-level-for-you.html)：成人全场为 78×36 英尺（双打）或 78×27 英尺（单打），换算并取两位小数分别为 23.77×10.97 米、23.77×8.23 米；红球短场 36×18 英尺，橙球中场 60×21 或 60×27 英尺。这些是边线尺寸，不包括缓冲区域。

两页均于 2026-09-22 浏览核对。ITF 链接的 PDF 下载遇到反爬页面，本次不引用未读取的 PDF 内容。练习场没有统一尺寸；不能通过选择“标准场”自动声称拥有认证或填写实测数据。

## 已实现的编辑方式

| 维度 | 选择或录入 |
| --- | --- |
| 场地材质 | 丙烯酸硬地、弹性丙烯酸硬地、红土、人造红土、天然草、人造草、聚氨酯 / 硅 PU、橡胶面层、地毯、沥青、混凝土、拼装地板、其他、未标注 |
| 场地环境 | 室内、室外、有顶棚且侧面开放 |
| 规格类型 | 标准全场（单打 / 双打）、标准单打场、练习 / 非标准场、儿童红球短场、儿童橙球中场、其他、未标注 |
| 照明条件 | 有照明、无照明、未标注 |
| 空调 / 通风 | 有空调、仅通风设备、无设备、未标注 |
| 材质细节 | 面层补充说明，用于型号、品牌、具体铺装工艺；混合红土等可用“其他材质”加说明 |
| 实测尺寸 | 边线内与包含缓冲区的整片区域，各自长、宽；单位米，可选填 |
| 客户可见说明 | 球网、练习墙、围网、净高、器材是否包含、用鞋和入场要求等自由说明 |
| 标准小时价 | 元 / 小时，最多两位小数；必填，0 为免费 |

材质选项使用国内运营者能辨认的名称，橡胶、硅 PU 等并非声称各自是 ITF 独立认证类别。尺寸不推导球速；本轮未增加无依据的球速等级、赛事认证或设施保证。

五个分类统一使用原生下拉框；仅“启用球场”使用复选框。可选实测尺寸折叠，主体沿用 GreenPMS 表单、弹窗及绿色按钮。只有一个“保存”按钮，创建时也可同时设置价格。

## 数据与权限契约

### 保存必填与日历展示（2026-09-22 最新确认）

- 保存前必须齐全：球场名称、标准小时价、环境（室内／室外／顶棚）、材质、规格。0 元有效；“未标注”不算已提供。日期、时段、场馆位置由页面相应区域提供。
- 新建环境必须明确选择，不默认室外。创建、编辑、单独改价均校验合并后五项必填，无论启用或停用，缺项都不能保存；不能清空价格或把材质／规格改回未标注。前端和后端同时拦截，后端失败不写资料、价格、版本或审计。
- 资料与价格权限仍独立：分别有权者可修改资料完整的已有场地对应部分；新建场地需要同时有资料和定价权限，在同一次保存中填写完整，不能通过停用草稿或默认 0 元绕过。
- 按用户明确授权，现有本地测试环境 8 片场地中 6 片缺失的材质／规格已模拟补为丙烯酸硬地／标准全场；保留原有价格、环境、已知规格和订单。补全记录与原资料备份保存在 `.local-workspace/court-required-save-20260922/`。未来生产资料不能沿用这一模拟补全行为。
- 管理页继续提示历史缺项；员工排场保留已启用场地和历史占用供查看，资料不足时不能新选购。客户查询和新报价只提供资料齐全的场地。已有订单与有效报价的原确认规则保留。
- 左侧紧凑卡片提供上述五项已知信息，不显示未标注或启用状态。弹框只补充照明、空调／通风、实测尺寸、面层说明和场地说明；空白项隐藏。没有补充信息时显示静态卡片，不提供弹框入口。
- 日期及左右切换放在表格左上角，保留“今天”按钮，移除“日期／球场”标题与重复的“现在”跳转按钮。

- migration 027 保留原球场及室内外、材质、价格，增加 covered 与 profile。旧资料未记录的规格、照明等返回“未标注”，不自动认定标准场或硬地。
- 新 `/courts/:id/profile` 接口将资料和价格放在同一事务；先验证相应资产、定价权限和当前版本，再写入。失败时两部分都不变，成功仅递增一次球场及场馆版本。
- 权限仍分开：只管资料或只管价格的人只能提交对应部分。旧资料与单独价格接口继续可用。跨租户、跨场馆校验及关闭球场前的有效占用检查保留。
- 基础小时价、时段折扣、整数分计价、资金和库存规则沿用。改价不追溯已确认订单；有效报价保留原价格快照，新报价使用新价格，确认时仍检查库存。
- 客户读取与外部智能体发现接口返回公开属性，仍受原租户及授权范围约束。后台助手工具返回可读属性名称；资料说明为公开内容，不能填写内部客户或财务隐私。
