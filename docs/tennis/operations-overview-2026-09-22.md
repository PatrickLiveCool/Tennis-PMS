# 经营概览分栏优化（2026-09-22）

本轮将原先纵向堆叠的今日预约、收款流水、企微对照、退款和异常拆成四个标签，沿用 GreenPMS 绿色主题、紧凑控件和原业务入口。

| 标签 | 内容与操作 |
| --- | --- |
| 工作台 | 今日资金摘要、按状态筛选的今日预约、待处理事项与资金查询入口 |
| 收款历史 | 日期、收款／余额消费／退款分类、流水或关联号搜索，每页 20 条 |
| 收款核对 | 管理员企微收款对照，切换标签时保留当前输入及未决提交恢复入口 |
| 退款与异常 | 当前场馆全部日期的待退款明细、实收待核对事项 |

标签、历史日期、预约筛选、流水分类、搜索和页码按身份／租户／上下文版本／场馆隔离保存。标签支持左右方向键及 Home / End；窄屏采用单列内容、两列资金摘要和表格内部横向滚动。模拟资金提示、错误及未决结果保持可见。

## 数据与权限

- 今日预约只展示当天有匹配明细的有效订单；金额标明“整单应付”，分页标明“本页”，不将单页数量当成当日总量。跨午夜预约展示两端日期。
- 入账收款、余额消费、现金退款、余额退回和充值赠送分别显示；筛选只影响流水列表，不改变当日合计。切换日期期间不将旧日期金额标成新日期金额。
- 退款与异常使用全日期数据，不受历史日期筛选影响，也不改写收款历史页码。
- 财务标签沿用 `manage_members` 权限；企微核对额外要求当前租户 ADMIN，普通前台不请求企微接口。企微流水保留“全部场馆收款／当前场馆核对”范围说明。
- 本轮不修改资金、退款、库存、接口或数据库规则。此前取消退款修复另见 PR #3。
